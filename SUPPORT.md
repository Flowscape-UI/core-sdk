# Flowscape Support

Flowscape is an open-source project and support is currently handled through GitHub Issues.

## Getting Help

For questions about Flowscape, open an issue in the repository:

https://github.com/Flowscape-UI/core-sdk/issues

You may use GitHub Issues for:

- usage questions
- setup problems
- API questions
- unexpected behavior
- rendering issues
- integration problems
- bug reports
- feature questions
- architecture questions related to using Flowscape

When asking for help, include enough context for the issue to be reproduced or understood.

Useful information may include:

- Flowscape version
- browser and operating system
- package manager/runtime version
- relevant code
- error messages
- screenshots or recordings
- steps to reproduce
- expected behavior
- actual behavior

For rendering or interaction issues, a minimal reproduction is especially helpful.

## Bug Reports

For bugs, clearly describe:

1. What you expected to happen.
2. What actually happened.
3. Steps to reproduce the problem.
4. The Flowscape version being used.
5. Relevant environment details.

Please search existing issues before opening a new one to avoid duplicates.

## Feature Requests

Feature requests are also welcome through GitHub Issues.

Please explain:

- the problem you are trying to solve
- the proposed behavior
- why the feature belongs in Flowscape
- possible alternatives
- expected impact on the public API, if known

Flowscape aims to provide reusable editor and graphics foundations rather than application-specific product features.

## Security Issues

Do **not** report security vulnerabilities through public GitHub Issues.

Follow the process described in:

[`SECURITY.md`](./SECURITY.md)

## Response Expectations

Flowscape is maintained as an open-source project.

Responses are provided on a best-effort basis, and there is currently no guaranteed response time or service-level agreement.

Clear reports with small reproductions are easier to investigate and are more likely to receive a useful response quickly.

## Before Opening an Issue

Please check:

- the README
- the documentation
- existing GitHub Issues
- the changelog

The answer may already be available there.

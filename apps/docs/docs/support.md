# Support

If you get stuck, use this order:

1. Check the documentation first.
2. Search the web for similar cases.
3. Ask an AI agent with a minimal reproducible example.

## Found a bug?

Create an issue in the project repository and include:

- clear title
- steps to reproduce
- expected result
- actual result
- environment details (OS, browser, package version)

[Open Issues Page](https://github.com/Flowscape-UI/core-sdk/issues)

# Donate

Flowscape is built as a long-term engine project, and community support directly helps keep development consistent.

## Why support Flowscape

- It helps fund ongoing core engine work, not only demos.
- It gives more time for bug fixes, documentation, and release quality.
- It accelerates development of editor-focused features for real product use.
- It keeps the project independent and focused on practical developer needs.

## What your support enables

- Better architecture and internal tools.
- Faster iteration on stability and performance.
- More examples, guides, and onboarding content.
- Healthier long-term maintenance.

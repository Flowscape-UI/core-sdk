## Why This Section Exists

The `Advanced` section is for engineers who want to go beyond basic usage.

Use it if you want to:

- understand how Flowscape internals are organized
- contribute fixes and features to the engine
- build custom extensions or your own engine layer on top of Flowscape

This section focuses on architecture, renderer/input details, and practical implementation patterns for engine-level work.
